🪙 델리오(Delio) 전용 도구

📸 거래내역 캡처 도구

델리오 거래내역 전 페이지를 자동 캡처하여 ZIP 파일로 다운로드합니다.

🔖 방법 1  추천  브라우저 북마클릿

Python 설치 불필요. 북마크 하나만 저장하면 클릭 한 번으로 캡처합니다.

1
아래 버튼을 북마크바로 드래그하세요

아래 버튼을 브라우저 북마크바(즐겨찾기 바)로 끌어다 놓으세요

📸 델리오 캡처
북마크바가 안 보이면: Chrome → Ctrl+Shift+B / Firefox → Ctrl+B
2
델리오에 로그인하고 거래내역 페이지로 이동

URL: https://deliobt.kr/transaction

3
코인 종류를 선택한 뒤 북마클릿 클릭

오른쪽 상단에 진행 창이 나타나고 전 페이지를 자동으로 캡처합니다.

4
완료되면 ZIP 파일이 자동 다운로드

파일명: delio_ETH_2025-01-15.zip 형태로 저장됩니다.

⚠️ 캡처 중 브라우저 탭을 닫거나 페이지를 이동하지 마세요. 완료될 때까지 기다려주세요.
🐍 방법 2  고급  Python 스크립트

북마클릿이 작동하지 않는 경우 Python 스크립트를 사용하세요. 캡처 품질이 더 정확합니다.

1
Python 3 설치

python.org에서 다운로드 후 설치 (PATH 체크 필수)

2
의존성 설치 (최초 1회) 
pip install playwright
python -m playwright install chromium
3
스크립트 다운로드 & 실행 
python capture_delio.py
브라우저가 열리면 로그인 → 자동 캡처 시작

📥 GitHub 저장소에서 파일 다운로드 (README 참고)

❓ 자주 묻는 질문
북마클릿 클릭 후 아무것도 안 나타납니다

델리오(deliobt.kr) 거래내역 페이지에서 실행했는지 확인하세요. 또한 일부 브라우저에서 보안 정책(CSP)으로 인해 외부 라이브러리 로딩이 차단될 수 있습니다. 이 경우 Python 스크립트(방법 2)를 사용하세요.

페이지 수가 잘못 감지됩니다

팝업창에서 직접 페이지 수를 입력할 수 있습니다. 델리오 화면에서 총 건수를 확인한 뒤 10으로 나눈 값을 입력하세요 (예: 53건 → 6페이지).

캡처된 이미지가 빈 화면입니다

html2canvas 라이브러리의 제한으로 일부 요소가 캡처되지 않을 수 있습니다. 이 경우 Python 스크립트가 더 정확한 결과를 제공합니다.

어떤 코인을 지원하나요?

URL의 coinType 파라미터에 맞게 자동으로 캡처합니다. 거래내역 페이지에서 ETH, BTC, USDT 등 원하는 코인을 선택한 뒤 북마클릿을 클릭하세요.

개인정보는 어디에 저장되나요?

이 도구는 서버가 없는 순수 브라우저 도구입니다. 모든 처리는 내 컴퓨터에서만 이루어지며, 캡처 데이터가 외부로 전송되지 않습니다.
