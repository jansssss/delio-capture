🔒 왜 즐겨찾기에 저장해야 하나요?
이 사이트는 델리오와 전혀 다른 주소에 있습니다.
보안상 다른 사이트끼리는 서로 접근할 수 없도록 브라우저가 막아두기 때문에,
이 버튼을 즐겨찾기에 저장해 두었다가 델리오 페이지에서 직접 클릭하는 방식을 사용합니다.
사이트 홍보나 개인정보 수집과는 전혀 관계없습니다. 😊
📌 이 버튼을 마우스로 잡고 위쪽 즐겨찾기 바에 올려놓으세요

3
저장할 코인을 클릭하세요
로그인하면 보유 중인 코인 목록이 나타납니다.
저장하고 싶은 코인을 클릭하면 거래내역 페이지로 이동합니다.
4
즐겨찾기 바에서 📸 버튼을 클릭하세요
브라우저 위쪽 즐겨찾기 바에 있는

파란 바가 100%가 될 때까지 창을 닫지 마세요!
5
파일 저장 창이 열리면 저장을 누르세요
저장 창이 열리면 바탕화면이 선택되어 있을 거예요.

📁 파일이 어디 있는지 모르겠다면? 바탕화면(컴퓨터 배경화면)을 보세요.
delio_ETH_날짜.zip 이라는 파일이 있을 거예요.
더블클릭하면 안에 사진 파일들이 들어있습니다.
6
다른 코인도 저장하려면 반복하세요
파일 저장이 완료되면 자동으로 코인 목록 페이지로 돌아갑니다.
다음 코인을 클릭하고 📸 버튼을 누르면 그 코인도 캡처됩니다.
🔄 코인별 반복 순서
코인 클릭 → 📸 버튼 클릭 → 저장 → 자동으로 목록 복귀
→ 다음 코인 클릭 → 📸 버튼 클릭 → 저장 → …

zip 파일이 뭔가요? 어떻게 열어요?

zip 파일은 여러 사진을 하나로 묶은 파일입니다.
파일을 더블클릭하면 안에 사진들이 보입니다.

Windows에서는 파일을 오른쪽 클릭 →압축 풀기를 누르면
사진 파일들이 폴더에 펼쳐집니다.

정상입니다! 숨겨진 창에서 페이지를 하나씩 열면서 사진을 찍고 있는 거예요.
오른쪽 위 파란색 진행 창이 완료! 라고 뜰 때까지 기다려 주세요.

캡처가 너무 오래 걸려요

페이지가 많을수록 시간이 오래 걸립니다.
1페이지당 약 3~5초 정도 소요됩니다.
예) 20페이지라면 약 1~2분 소요.
